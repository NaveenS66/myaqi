# AQI Sentinel — 3-Minute Judge Demo

## 0:00–0:20 — The decision gap
“Cities already receive AQI readings. AQI Sentinel adds the missing decision layer: which location, which likely source category, what response, and how urgently.”

## 0:20–0:55 — Detect and forecast
Select a station and show the data-status label.

“The green **Holdout Evaluated** badge means the metric comes from a time-ordered evaluation against persistence. Amber means this is a clearly labelled demo scenario, not an accuracy claim.”

## 0:55–1:45 — Explain and intervene
Show the forecast, likely source categories, confidence, and ranked action list.

“This is inspection prioritisation, not causal proof. The system makes its evidence state visible so officers can verify it in the field.”

## 1:45–2:20 — Protect people
Switch the advisory to Hindi, Kannada, or Tamil.

“The same incident becomes an understandable local health advisory.”

## 2:20–3:00 — Scale and close
Toggle cities and show the architecture.

“Each city needs station, regulated-source and land-use onboarding—not a new product. AQI Sentinel turns a pollution signal into a transparent, evidence-backed intervention workflow.”
