# Judge Q&A — Evidence-First Answers

## Is this causal source attribution?

No. It is a ranked inspection hypothesis from wind direction, source-registry proximity and land-use cues. Officers must verify it in the field before action.

## Are the forecasts proven accurate?

Only forecasts that display **Holdout Evaluated** have saved station-level RMSE against persistence. A demo scenario is explicitly labelled and is not an accuracy claim.

## What happens when data is missing?

The platform marks it unavailable. It does not fabricate live AQI, a forecast, or an enforcement recommendation.

## Why does a city need this rather than a dashboard?

A dashboard reports a condition. AQI Sentinel creates an accountable workflow: evidence, priority, owner, recommended action, and verification outcome.

## How does it scale?

The product separates the core workflow from city-specific onboarding. New cities add station feeds, regulated-source layers, local languages and response protocols.

## What is the first production investment?

A pilot integration with authenticated station data and one city’s source/permit registries, followed by a shadow-mode validation period.
