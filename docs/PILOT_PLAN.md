# 90-Day Municipal Pilot Plan

## Objective

Test whether AQI Sentinel helps a city move from a pollution signal to a documented, field-verifiable intervention faster than the current manual workflow.

## Scope

- One city, 10–20 CAAQMS stations, and 3–5 high-risk wards.
- Initial source layers: regulated industries, active construction permits, major corridors, and reported open-burning locations.
- City-owned operations team reviews every recommendation; the platform never issues an enforcement order.

## Phases

| Phase | Days | Output |
|---|---:|---|
| Data readiness | 1–30 | Station quality check, source registry onboarding, response protocol |
| Shadow mode | 31–60 | Ranked priorities run alongside the existing process; no operational reliance |
| Guided intervention | 61–90 | Officers use field-verified priorities; outcomes are recorded |

## Success metrics

| Metric | Measurement | Target decision |
|---|---|---|
| Signal-to-assignment time | AQI trigger to accountable field task | Compare with baseline workflow |
| Recommendation precision | Share of reviewed priorities with a verified actionable source category | Improve after registry calibration |
| Forecast quality | Station-level RMSE against persistence | Deploy only where the model beats baseline |
| Intervention traceability | Share of actions with evidence, owner, outcome, and closure time | Demonstrate accountable operations |
| Advisory reach | Ward-language advisory delivery and acknowledgement | Measure public-health communication coverage |

## Decision after 90 days

Expand only if the evidence ledger shows a measurable response-time improvement, transparent model performance, and officers consider the recommendations useful after field verification.
